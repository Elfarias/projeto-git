Este projeto foi criado para consolidar conhecimentos sobre controle de versão, GitHub, colaboração e boas práticas utilizadas por desenvolvedores profissionais.

Introdução

Git é um sistema de controle de versão distribuído utilizado por milhões de desenvolvedores.

💡 Aprender Git é uma habilidade obrigatória para desenvolvimento moderno.

O que é Git?

Git permite rastrear alterações em arquivos, colaborar em equipe e recuperar versões anteriores do projeto.

O que é GitHub?

Plataforma de hospedagem de repositórios Git.

Comandos Essenciais

git init

Cria um novo repositório Git.

git status

Mostra o estado atual do repositório.

git add .

Adiciona arquivos ao Stage.

git commit

Cria um snapshot do projeto.

git push

Envia alterações ao GitHub.

Branches

git branch feature-login

git checkout feature-login

Merge

git checkout main

git merge feature-login
