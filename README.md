\## 🛠️ Comandos Git Utilizados



Inicializar repositório:



```bash

git init

```



Adicionar arquivos:



```bash

git add .

```



Criar commit:



```bash

git commit -m "Primeiro commit"

```



Conectar ao GitHub:



```bash

git remote add origin URL\_DO\_REPOSITORIO

```



Enviar código:



```bash

git push -u origin main

```



Ver histórico:



```bash

git log --oneline

```
