🛠️ Comandos Git Utilizados
Inicializar repositório:

Bash
git init
Adicionar arquivos:

Bash
git add .
Criar commit:

Bash
git commit -m "Primeiro commit"
Conectar ao GitHub:

Bash
git remote add origin URL_DO_REPOSITORIO
Enviar código:

Bash
git push -u origin main
Ver histórico:

Bash
git log --oneline
